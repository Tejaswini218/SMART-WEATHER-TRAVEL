# Smart Weather and Travel

## 📌 Project Description

Smart Weather and Travel is a web application that combines weather information with travel planning features. It helps users check weather conditions for a destination and make better travel decisions based on the current weather.

## ✨ Features

- 🌤️ Search weather by city or destination
- 🌡️ Display temperature
- 💧 Display humidity
- 💨 Display wind speed
- ☁️ Display weather conditions
- 🧳 Travel planning support
- 📍 Destination-based information
- ❌ Error handling
- ⏳ Loading indicators
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
